# Grafiki

## Introduction
Grafiki is a creative video editing tool designed to help you turn raw footage into complete edited videos. This program is especially meant for those who are looking to give their editing projects chaotic and abstract effects. 

The application offers an approachable sandbox where you can intuitively experiment with visual filters and real-time tweaks. For those who want to go deeper, Grafiki provides complete technical control by letting you modify and rewrite the underlying effect code directly, giving you unlimited freedom to engineer your own custom visuals.
